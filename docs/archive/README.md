# Documentation Archive

This directory contains historical documentation that has been archived. Documents are organized by category for easy reference.

## Archive Structure

### `sessions/`
Session-specific reports and summaries from completed work sessions. These documents capture historical context but are no longer actively maintained.

### `blocking-fixes-b1-b4/`
Documentation related to blocking fixes B1-B4 that were **resolved in commit 279e395**. These issues are now closed and this documentation is preserved for historical reference.

### `investigations/`
Completed investigations and research documents. The findings from these investigations have been incorporated into active documentation or implemented in code.

### `backups/`
Backup comparison reports and file listings from system backups.

## Archive Policy

Documents are archived when:
1. **Session reports** - Work is complete and findings are incorporated into active docs
2. **Resolved issues** - Bugs/blockers are fixed and verified in production code
3. **Superseded specs** - Requirements are replaced by newer canonical documents
4. **Historical context** - Information is valuable for reference but no longer drives current work

## Retrieval

If you need to reference archived documentation:
1. Check the relevant subdirectory based on document type
2. Each archived document retains its original filename for traceability
3. Cross-references in active documentation may point to archived files
